# Firsat Radar

Firsat Radar is a local-first product opportunity research application planned around traceable, permitted e-commerce data.

## Current status

Stage 0 data-access discovery is complete with a `STOP` decision. The current environment received an HTTP 403 security response from Hepsiburada during the first low-impact live request. No application or crawler code will be implemented until an approved data-access path or an alternative source is selected.

See [ADR 0001](docs/adr/0001-data-access.md) and [HANDOFF.md](HANDOFF.md) for evidence and next steps.
